## 使用

 **npm安装之后，`/`会加载出这个skill**
 - 好像有一点问题，有些ai不会加载出来，应该是我包的原因，我后续改善吧
    
**在对话里把skill.md文件发给你的chatAI，它也能读取到markdown文件**
 - 最稳妥的方式，用起来比较麻烦，每次对话都要发一遍这个文件
    
**直接把`skill.md`放到AI对应的路径文件下，也可以在`.agent`里新建一个`skills文件`把[鲍文锋skill.md](鲍文锋skill.md)放进去，**
 - 最实用的方法，基本没有问题
